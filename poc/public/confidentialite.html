Règles de confidentialité – Done Juan

Dernière mise à jour : 25 octobre 2026.

Done Juan est une application personnelle de suivi d'objectifs et de tâches, en cours de développement. L'application publiée à cette adresse est une version de test (« Diagnostic ») : elle sert à vérifier la connexion à Google et l'enregistrement des données sur l'appareil.

En bref

  • Nous ne collectons aucune donnée. L'application n'a pas de serveur : elle fonctionne entièrement dans votre navigateur.
  • Vos données restent dans votre propre Google Drive et sur votre appareil. Personne d'autre que vous n'y a accès.
  • Aucune publicité, aucune mesure d'audience, aucun cookie de suivi. Rien n'est vendu ni partagé.

Accès demandés à votre compte Google

  • openid et email : connaître votre adresse e-mail, pour afficher le compte connecté et séparer les données de plusieurs comptes sur un même appareil.
  • drive.file : créer, lire et modifier uniquement les fichiers que l'application a elle-même créés dans votre Google Drive (dossier « Done Juan (POC) »), ou que vous choisissez vous-même dans le sélecteur de fichiers de Google. L'application n'a pas accès à vos autres fichiers.

L'application n'accède ni à votre agenda, ni à vos contacts, ni à vos e-mails. Si une version future demande un nouvel accès (par exemple à Google Agenda), cette page sera mise à jour avant, et Google vous demandera votre accord.

Où sont vos données

  • Dans votre Google Drive : les fichiers créés par l'application, dans le dossier « Done Juan (POC) ».
  • Sur votre appareil, dans le stockage du navigateur : votre adresse e-mail, le journal de diagnostic et un marqueur de test.
  • Le jeton d'accès fourni par Google reste en mémoire le temps de la session. Il n'est jamais enregistré ni transmis à qui que ce soit d'autre que Google.

Les pages sont hébergées par GitHub (GitHub Pages). Comme tout hébergeur, GitHub reçoit l'adresse IP des visiteurs pour leur envoyer les pages : voir la déclaration de confidentialité de GitHub. La connexion passe par Google : voir les règles de confidentialité de Google.

Utilisation limitée des données Google

L'utilisation et le transfert des informations reçues des API Google respectent la règle relative aux données utilisateur des services d'API Google (Google API Services User Data Policy), y compris les exigences d'utilisation limitée (« Limited Use »).

Garder la main sur vos données

  • Supprimer vos données : supprimez le dossier « Done Juan (POC) » de votre Google Drive, puis effacez les données du site dans votre navigateur (ou désinstallez l'application).
  • Retirer l'accès de l'application à votre compte : myaccount.google.com/connections, « Done Juan », « Supprimer l'accès ».

Contact

Pour toute question : ouvrez un ticket sur github.com/mathieublandin-create/taskapp/issues, ou écrivez à l'adresse d'assistance que Google affiche sur son écran de connexion (cliquez sur le nom de l'application).
