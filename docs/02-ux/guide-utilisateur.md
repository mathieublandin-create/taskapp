# Guide utilisateur

> **Version 0.1, 2026-10-20 (Steeve) : squelette.** Ce guide est destiné à l'utilisateur final. Il est rédigé par tâches (« Comment… ») et illustré de captures d'écran. Il est complété à la clôture de chaque lot (étape E17) et ne décrit que des fonctions **livrées**.
>
> Légende de l'état des sections :
> - *À rédiger (LOT-xxx)* : la fonction est prévue dans ce lot ;
> - *À rédiger (lot à venir)* : la fonction est prévue dans un lot qui n'est pas encore constitué ;
> - *Rédigée (LOT-xxx)* : la section est à jour.
>
> Règles de rédaction : vouvoiement ; phrases courtes ; une tâche par section ; étapes numérotées ; une capture par écran cité (`images/GU-xx-<nom>.png`, smartphone d'abord, PC si l'écran diffère) ; mêmes termes qu'à l'écran (voir le §8 du [guide d'ergonomie](guide-ergonomie.md)).
