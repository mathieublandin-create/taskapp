Règles de confidentialité – Done Juan

Dernière mise à jour : 10 novembre 2026.

Done Juan est une application personnelle de suivi d'objectifs et de tâches, utilisable sur ordinateur et sur téléphone, même sans réseau.

En bref

  • Nous ne collectons aucune donnée. L'application n'a pas de serveur : elle fonctionne entièrement dans votre navigateur.
  • Vos données restent dans votre propre Google Drive et sur votre appareil. L'application ne les partage avec personne et aucun serveur du projet n'y accède. Votre Google Drive reste soumis aux règles de Google et à vos propres réglages de partage.
  • Aucune publicité, aucune mesure d'audience, aucun cookie de suivi. Rien n'est vendu ni partagé.

Accès demandés à votre compte Google

  • openid et email : identifier votre compte Google, pour afficher le compte connecté, séparer les données de plusieurs comptes sur un même appareil et vérifier que vos appareils utilisent le même compte.
  • drive.file : créer, lire et modifier uniquement les fichiers que l'application a elle-même créés dans votre Google Drive (dossier « Done Juan »). L'application n'a pas accès à vos autres fichiers. Elle n'accède ni à votre agenda, ni à vos contacts, ni à vos e-mails. Si une version future demande un nouvel accès (par exemple à Google Agenda), cette page sera mise à jour avant, et Google vous demandera votre accord.

Où sont vos données

  • Dans votre Google Drive, dans le dossier « Done Juan » créé par l'application : un fichier de données par appareil, un fichier d'index (manifeste.json) et un fichier explicatif (LISEZ-MOI.txt).
  • Sur votre appareil, dans le stockage du navigateur : vos objectifs, vos tâches et leur historique, le compte Google connecté, et un journal technique qui ne contient aucun contenu de vos objectifs ni de vos tâches.
  • Le jeton d'accès fourni par Google reste en mémoire le temps de la session. Il n'est jamais enregistré ni transmis à qui que ce soit d'autre que Google.

Les pages sont hébergées par GitHub (GitHub Pages). Comme tout hébergeur, GitHub reçoit l'adresse IP des visiteurs pour leur envoyer les pages : voir la déclaration de confidentialité de GitHub. La connexion passe par Google : voir les règles de confidentialité de Google.

Utilisation limitée des données Google

L'utilisation et le transfert des informations reçues des API Google respectent la règle relative aux données utilisateur des services d'API Google (Google API Services User Data Policy), y compris les exigences d'utilisation limitée (« Limited Use »).

Garder la main sur vos données

  • Supprimer vos données : supprimez le dossier « Done Juan » de votre Google Drive, puis effacez les données du site dans votre navigateur (ou désinstallez l'application).
  • Retirer l'accès de l'application à votre compte : myaccount.google.com/connections, « Done Juan », « Supprimer l'accès ».

Contact

Pour toute question : ouvrez un ticket sur github.com/mathieublandin-create/taskapp/issues, ou écrivez à l'adresse d'assistance que Google affiche sur son écran de connexion (cliquez sur le nom de l'application).
